WHAT THIS PAGE IS — AND IS NOT

    

      
WEB WALLET BACKUP
Backup of the official browser wallet at https://sostcore.com/sost-wallet.html (PBKDF2 + AES-256-GCM). Different format — not readable by sost-miner.

      
CLI / MINER V2 WALLET
File written by sost-cli wallet-export --encrypted (scrypt N=32768 r=8 p=1 + AES-256-GCM). Read directly by sost-cli and sost-miner. This page writes exactly this format.

    

    
This page cannot: change file permissions, write into WSL, start or stop sost-miner, protect against malware already running as your user, or recover a forgotten passphrase. A browser cannot guarantee that memory is wiped; the page drops passphrases and decrypted data as soon as practical. There is deliberately no "decrypt to plain text" button — use sost-cli wallet-import --encrypted for recovery.
