# SOST release public key — install location

The **public** release key goes here (public material only; never a private key):

  keys/sost-release.pub    (minisign)   — or   keys/sost-release.asc   (GPG)

It is also published at  https://sostcore.com/keys/sost-release.pub

This file is intentionally empty of any key until the owner installs the real
PUBLIC key generated OFFLINE (see docs/v30000/OFFLINE_SIGNING_RUNBOOK.md).
No private key is ever stored in this repo, on the VPS, in CI, or on GitHub.
