Usage

Using the logo

Keep clear space of at least 10 % of the logo width on every side. Minimum size 24 px on screen (32 px or more recommended), 10 mm in print.

Correct

  • Use the files of this kit as supplied, scaled uniformly.
  • Prefer dark backgrounds; on light ones use the transparent files.
  • Use the circle-safe icons where a platform crops to a circle.
  • Write the name as Sovereign Stock Token — SOST, or SOST where only the ticker fits.

Incorrect

  • Stretching, skewing, rotating or cropping the logo.
  • Recolouring (the Σ is always gold), outlines, shadows or effects.
  • Redrawing, tracing or recreating the logo with generative tools.
  • Presenting the legacy logo, or any other emblem, as the current SOST logo.
  • Any other name or variant of the name.
