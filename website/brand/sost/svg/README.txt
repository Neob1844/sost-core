No SVG vector is provided for the SOST logo.

The logo is a luminous, photographic illustration (light ribbons, glow, reflections).
Tracing it into vector paths would visibly alter the artwork, and an SVG that only embeds a PNG
is not a real vector file, so neither is published as "SVG".

Canonical files: ../original/ (byte-identical original artwork, 1254 px) and ../png/ (2048-32 px).
Square icons for exchanges and wallets: ../../exchange/
