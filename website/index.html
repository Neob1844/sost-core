Method and limits

Share = blocks of one address ÷ blocks in the window. HHI (Herfindahl–Hirschman index) = Σ share², with shares in %, so 10,000 = one producer. Nakamoto coefficient = the fewest addresses that together produced more than 50 % of the blocks.

Windows. The two boxes use the newest 1,200 and 288 rows. The history splits the same series into consecutive, non-overlapping 288-block windows ending at the newest block; an incomplete oldest window is dropped.

An address is not an entity. One person can mine to many addresses and one address can be shared, so these counts say nothing certain about how many people mine.

Block production is not hashrate. Blocks found in a window depend on luck and timing as well as on work; no hashrate, ownership or intent is inferred from them.

Overview

What SOST is

SOST (Sovereign Stock Token) is a native Layer 1 blockchain secured by proof-of-work. It has no ICO, no premine and no venture allocation. The consensus rules changed only through network-adopted upgrades at announced heights (V13, V15, V30000); see governance.

Time

600 s blocks

144 blocks a day. cASERT sets two separate things: bitsQ (Q16.16 numeric target, from the 288-block average, ±15 s dead band) and the Equalizer profile (43 profiles, E7–H35).

cASERT spec
Work

ConvergenceX

Memory-hard CPU proof-of-work: 4 GB dataset + 4 GB scratchpad, 8 GB of RAM in total for mining (threads share one scratchpad). Verification needs about 500 MB, no dataset.

Technology
Scarcity

≈ 4,669,201 SOST

Asymptotic cap (Feigenbaum δ × 10⁶). The reward decays by e−1/4 each epoch of 131,553 blocks (~2.5 years); about 95 % is mined in ~12 epochs.

DTD and DTD Jackpot ACTIVE

Value returns to the people who run the network

Two deterministic, keyless, supply-neutral draws. Same blocks + same rules + same state = same result: anyone can recompute every winner. Nothing here is random and nothing is a promise of gain.

① Normal DTD · every block

Half of each block's subsidy goes to one eligible miner. Eligibility: an SbPoW-signed block in the last 288 blocks (since #30,000), a 6-block cooldown that yields if it would empty the set, and anti-dominance (≥ 10 % of 288 blocks) armed only with ≥ 11 distinct miners.

Seed: SHA256("SOST_LOTTERY_V11" ‖ hashes h−16…h−1 ‖ h) mod the size of the sorted eligible list. History: 2-of-3 blocks at #7,100, 1-of-3 from #12,100, every block since V15 (#25,000).

② DTD Jackpot V2 · every 288 blocks

Drains the reserve accumulated before #25,000: base 100 SOST, cap 500, at heights #25,290 + 288k. Since #30,000 (first V2 draw #30,186): NODE_BIND + heartbeats in 3 of the last 4 epochs + ≥ 3 SbPoW blocks in the last 2,016, weighted by those blocks; no cooldown or anti-dominance; rollover when nobody is eligible.

Seed: SHA256("SOST_HIST_JACKPOT" ‖ 16 hashes ‖ h) mod total weight. #25,290–#29,898 paid the DTD winner (historical rule).

Audit & verify

What you can check today, and what is not claimed

Verifiable

Source code Neob1844/sost-core · genesis_block.json · emission split in include/sost/params.h (50/25/25 for #0–#24,999, 50/50 from #25,000) · SbPoW signatures from #7,100 · anti-dominance in src/lottery.cpp · deterministic builds · every DTD and Jackpot winner recomputable from block hashes.

Not claimed

No post-quantum safety (ECDSA today; PQ is research). No external security audit. No price floor, peg or redemption. No regulatory clearance. No exchange listing. The network is young; few addresses produce most blocks today (measured above). Honest assessment

Research RESEARCH

#40,000 — V17 proposed upgrade (not active)

V17 is a release candidate under testing: no release has been published and nothing is active. Proposed from #40,000: 80 % miner / 15 % DTD / 5 % into a Jackpot accumulator (no new supply), a PoW-commit winner seed, full re-execution of ConvergenceX proofs and native multisig. Native assets and the wSOST bridge are not part of V17. If the release criteria are not met, nothing activates (the only alternative height prepared is #50,000). Current consensus is unchanged: 50 % miner / 50 % DTD. Read the notice
