DURING THE WINDOW #39,900 - #39,999 (node first, then miner)

[ ] Old miner stopped; pgrep -a sost-miner prints nothing
[ ] Executable replaced with the verified V17 sost-miner
[ ] Same address, wallet, key label and flags (--realtime stays)
[ ] Miner reaches the node and gets work (no RPC errors)
[ ] My next block is accepted and shown on the Explorer with my address
[ ] No old miner still running anywhere with the same address

IF THE MINER CANNOT BE UPGRADED IN TIME
