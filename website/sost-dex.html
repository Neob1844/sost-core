Connect wallets

A cross-chain swap needs a SOST wallet and the counterparty-chain wallet. The DEX never sees any seed or private key — it only requests addresses and signatures.

SOST network
Counterparty · EVM / Bitcoin

EVM via EIP-6963/EIP-1193 (MetaMask, Rabby, Coinbase). Bitcoin via Xverse/UniSat — a wallet is only usable if it can sign PSBTs (P2WSH claim/refund), not just send BTC.

Security · 2FA for sensitive actions

Optional local authenticator (TOTP) gate before connecting a wallet or executing a swap. Local to this browser; a UX safeguard, not custody security — your wallet's own signature prompt is the real control.
