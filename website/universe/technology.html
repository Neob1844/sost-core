Four ideas

Convergence, memory, validation, consensus

Mathematical convergence

Instead of brute-force hash collision, ConvergenceX requires miners to produce verifiable convergence certificates using Transcript V2. Each attempt solves a tip-bound linear system via deterministic gradient descent, mixed with memory-hard scratchpad reads, and proves the solution lies in a stable convergence basin.

Memory

Mining is memory-hard (ASIC resistant), but verification is lightweight (anyone can run a node). The miner must build and hold the full 4 GB dataset and 4 GB scratchpad in memory to solve the ConvergenceX puzzle.

Validation

The node only verifies the compact Transcript V2 proof — SHA256 hashes and merkle checks, no dataset required.

Consensus

Integer-only arithmetic · Zero floating point · Deterministic across all nodes
